The first MVP for the app

1. For gym owner:

  - register as owner
  - display their gym brand and information (name, picture, localisation + coordonate, etc ...)
  - interact to public advice and note

2. For public:

  - listing gym
  - basic filter: distance, location, (other information that can be added to filter)
  - see the gym informations
  - set note and advice

3. Feature
  - Auth simple (email/Google).
  - Trusted Geolocalisation.
